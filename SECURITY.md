# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.3.x   | ✅        |
| < 0.3   | ❌        |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities privately via GitHub's built-in mechanism:
👉 [Report a vulnerability](https://github.com/mondi04/htmforge/security/advisories/new)

Include in your report:
- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

You will receive a response within **7 days**.
Fixes will be released as a patch version and disclosed
in the changelog after a fix is available.
